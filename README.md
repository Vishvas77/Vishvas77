### 🔺 Memory Allocator Simulator

**Problem** — Analyzing dynamic memory allocation policies, heap fragmentation, and allocation failures under arbitrary workloads requires deep runtime visibility.

**Solution** — A modular C11 memory management laboratory simulating a fixed 1024-byte pool, implementing dynamic block splitting, instant adjacent block coalescing, real-time ASCII heap topology visualization, and single-pass fragmentation diagnostics.

**Stack** — `C (C11)` · `Make` · `GCC/Clang` · `GDB` · `Valgrind` · `GitHub Actions`

**Evidence** — [Repository](https://github.com/Vishvas77/memory-allocator-simulator)

<details>
<summary>Architecture & Technical Detail</summary>

- **Block Topology**: Doubly linked list block header architecture enabling $O(1)$ neighbor traversal for instant coalescing.
- **Fragmentation Reduction**: Dynamic block splitting reduces internal waste on oversized matches; adjacent block coalescing recovers contiguous free space upon deallocation.
- **Strategy Engine**: Comparative analysis across First Fit (fast traversal), Best Fit (exact sizing), and Worst Fit (stress testing).
- **Diagnostics**: Single $O(N)$ pass metrics engine calculating internal/external fragmentation percentages and largest contiguous block availability.

</details>
